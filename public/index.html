Instalación

  1. Pulsa Instalar automáticamente — copia el plugin a %LOCALAPPDATA%\Roblox\Plugins por ti.
  2. Abre Roblox Studio — el widget se abre solo, flotando en el centro.
  3. Si el servidor no corre, arráncalo: node server.js en la carpeta del proyecto.
  4. Pide lo que quieras: el agente crea partes directamente, inserta scripts, inspecciona y edita tu place.

¿Cómo funciona el modo agente?

1Escribes en la web o en Studio — misma conversación compartida en el servidor local.
→
2La IA responde y, si hay que actuar, emite acciones (create_instance, insert_script, set_property…).
→
3El plugin ejecuta cada acción en Studio — aunque el widget esté cerrado — y devuelve el resultado al chat.
→
4La IA lee el resultado y continúa: loop agéntico completo dentro de Roblox.
